# Performance Reviewer Skill

Review the application for runtime efficiency and system resource management.

## Focus Areas
- **Compose Stability**: Identify unstable types causing unnecessary recompositions.
- **Memory Management**: Detect potential leaks in long-running Flows or static references.
- **Networking**: Audit API call frequency and redundant data fetching.
- **Disk IO**: Review Room database access patterns.

## Output
Generate a "Performance Scorecard" with specific bottlenecks and their corresponding optimization strategies.

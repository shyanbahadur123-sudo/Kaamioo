# Senior UI/UX Reviewer Skill

Review the Kaamio user interface for consistency, premium feel, and perfect execution of the "Quiet Luxury" aesthetic.

## UI Checklist
- **Visual Hierarchy**: Is the primary action (Call-to-Action) clear?
- **Spacing**: Does the layout follow the 8dp grid? Is there sufficient breathing room?
- **Typography**: Are weights used to define importance? Is letter spacing consistent with editorial design?
- **Motion**: Are transitions smooth? Does physical motion (scale/bounce) feel balanced?
- **States**: Are loading, empty, and error states visually integrated into the screen design?

## Rating
Rate every screen from 0 to 10 and provide specific visual refinements.
